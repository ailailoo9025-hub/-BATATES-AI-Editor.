# BATATES AI Editor — v0.3 highlight-radar preview

## Included
- Tablet-first dark Flutter workspace.
- Import one or multiple local video files, preview, play/pause, and select clips.
- Manual trim controls and 9:16 / 16:9 MP4 export.
- Audio-energy scan: samples the recording in 8-second windows, reads FFmpeg peak volume, ranks energetic windows, and displays candidate timestamps with an explainable audio-energy score.
- One-tap auto edit exports the highest-scored candidate after scanning; without a scan it exports up to the first 30 seconds.
- Android share sheet for exported MP4.

## Important limitations
This is an early functional editor prototype, not full semantic AI. The radar measures audio intensity only. It does not determine whether a moment is funny, detect laughter or speech meaning, recognize game events/faces, analyze chat, or connect to live streams. Loud audio can be noise and quiet highlights can be missed. It currently exports one selected segment, not a multi-clip montage or editable professional timeline. Local videos are selected from the device; social-platform link downloading is not included.

## Build
The GitHub Actions workflow in `.github/workflows/android-apk.yml` creates the Android platform scaffold, resolves Flutter packages, builds a release APK, and uploads it as an Actions artifact.

For local development, install Flutter and Android Studio, then run:
```sh
flutter create --platforms=android --org com.batates.editor .
flutter pub get
flutter run
flutter build apk --release
```

APK output: `build/app/outputs/flutter-apk/app-release.apk`.
